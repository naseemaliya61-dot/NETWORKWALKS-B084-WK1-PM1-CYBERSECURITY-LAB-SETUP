# Week 1: Cybersecurity Lab Setup

## Overview
This project documents my Week 1 cybersecurity lab setup using Oracle VirtualBox and Kali Linux as part of my cybersecurity learning journey with NETWORKWALKS.

## Objectives
- Install and configure Oracle VirtualBox.
- Set up a Kali Linux virtual machine.
- Configure the NAT Network.
- Verify network connectivity.
- Enable shared folders and drag-and-drop.
- Create a snapshot as a backup.

## Lab Environment
- **Virtualization Software:** Oracle VirtualBox 7.2.22
- **Operating System:** Kali Linux
- **Network Type:** NAT Network
- **Network Prefix:** 10.0.0.0/24

## Network Configuration
- **Required Kali Linux IP:** 10.0.0.2/24
- **Expected Gateway:** 10.0.0.1

## Setup Process
1. Installed Oracle VirtualBox.
2. Set up the Kali Linux virtual machine.
3. Configured the NAT Network.
4. Worked through network configuration and connectivity issues.
5. Prepared the environment for verification and snapshot backup.

## Challenges and Troubleshooting
During setup, I encountered network configuration issues, including an IP address conflict while attempting to configure 10.0.0.2. I worked through the troubleshooting process step by step and learned more about virtual networking.
